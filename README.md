# Longship
Originally created for the 2026 WWT STEM Student Forum. This solution was designed to improve supply chain efficiency of teachers getting classroom supplies from the bookstore using Google Workspace. We've open sourced our solution for anyone to use.

## Info
 - This system is called Longship, and it uses Google Apps Scripts to improve supply chain efficiency
 - There is an inventory Google Sheet. This contains inventory data and email authorization (meaning who can actually request supplies)
 - Any change to the data of the inventory in the Google Sheet is logged in a sheet called "Log"
 - This inventory Google Sheet is connected to an order Google Form. This form is where teachers/employees place their orders for supplies. The form is automatically updated every morning to stay up to date with the inventory data in the inventory Google Sheet
 - Upon placing an order, the next-in-command will recieve an email with the order information. They can then reply to the email with "Approved" or "Denied"
 - Approving will send the order to the next-in-command if there is one, or automatically reduct the ordered items from the inventory Google Sheet if they are the highest in command
 - Denying will cancel the order
 - Every Monday morning, the highest-in-command will recieve an inventory report generated by Google Gemini, giving a quick summary on inventory data, the items most in demand, and predicting when items will run out

## Instructions (get your own Longship to use)
- Go to the [Longship Google Drive Folder](https://drive.google.com/drive/u/1/folders/1livWnilfSNy-C8Qe9m4WtmpLISzWBzKF)
- Download the folder onto your computer (it will download as a zip file)
- Upload the zip file back into your own drive
- Add your own inventory data in the "Inventory" Google Sheet
- Change up the emails in the "Inventory" Google Sheet
- And you're done!
